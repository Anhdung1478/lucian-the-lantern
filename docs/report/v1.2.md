# V1.2 report: node states, a living lantern tree, ornate menus and a purchase pop-up

**Date:** 2026-11-05 · **Branch:** `v1.2` (commits `595f230..150a729`, the last code commit, then one docs commit with this report; not pushed; `main` gets them by a fast-forward) · **Plan:** `docs/implementation/v1.2.md` · **Spec:** `docs/superpowers/specs/2026-11-04-v1.2-tree-and-menus-design.md`

## Summary

The Evolution Tree, the menus and the Skin Shop got a new look. Nothing in gameplay changed.
- **Node states:** a node is grey and silver until bought, gold while in progress and green with a ✔ crest and "MAX" when done. A level bar sits under it, and a ▲ chip shows when you can buy it now.
- **A living lantern tree** (`TreeArt`): bark, roots on a grassy mound, tapering boughs, leafy crowns, little lanterns that light when a node is bought, and gold light that climbs to bought nodes.
- **Ornate menus:** the stage's ESC menu, the gear menu and the Yes / No pop-up are one card over a blurred game (`MenuBackdrop`, `MenuCard`, `MenuEntry`).
- **The Skin Shop asks before it buys:** Purchase opens a pop-up with the skin's bonuses, weaknesses, price, purple owned and what is left (`SkinPurchasePopup`).
- **Version 1.2.0** is set in `project.godot` and `export_presets.cfg`, and the README names the new zip.

The test suite grew from **1653 to 1681 tests**, and all of them pass.

## Known limits

- **Summoners has no lanterns and Stats has 2.** The rule skips a lantern that would touch a node, and those pages are crowded.
- **"Leave to main menu"'s hint** ("Title screen") sits tight against its label.
- **In the overwrite question,** the gear card's medallion shows faintly through the pop-up's top edge, and so does its "SAVE AS COPY" title.
- **The ESC and gear backdrop blur** is a light 13-tap blur, so small text behind the card is still half readable.
- **On the Summoners page** the hidden "?" nodes show as dark boxes over the canopy, which looks a little heavy.
- **Tests:**
  - `test_monsters`'s raptor-spread test waits on wall-clock time and can fail under load (known since Phase 10).
  - The full suite takes about 11 minutes.

## Fixes from the final review

- **Docs:** the Leave note in The menus, the lantern line in docs/main_screen.md and the subtitle example in docs/ui_design.md now say what the code does.
- **Chips:** the ▲ and ✔ chips sit 7 px lower (centre y 9), so they no longer touch the name plate of the node above in vertical chains. The tree screenshots are re-taken.
- **Tests:** two new tests, one for the chips (none overlaps another node's drawing, on every page) and one for ESC closing the skin purchase pop-up without opening the menu. The suite is now 1683 tests, all passing.

## Manual playtest checklist (for you)

1. **Buy a level in the Evolution Tree:** watch its lantern light and the gold light climb to the node. Check the frame goes gold, then green with a crest at max.
2. **ESC in a stage:** check the card, the stage's name under MENU, the red hover on Leave and Exit, and ESC closing it.
3. **The gear menu on the main screen:** check Save, Save as copy (the SAVE AS COPY page), Leave and Exit.
4. **Skin Shop:** Purchase, then Cancel (nothing spent). Then Purchase, then Purchase (the price is spent, the card reads Equip). Check ESC closes the pop-up.
5. **Low effects:** check the tree shows no climbing light.
