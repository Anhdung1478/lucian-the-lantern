# V1.1 report: skin effects for Q, W, E and R, and a Skin Shop preview

**Date:** 2026-10-31 · **Branch:** `v1.1` (commits `2c3eefb..bebd82f`, the last code commit, then one docs commit with this report; not pushed; `main` gets them by a fast-forward) · **Plan:** `docs/implementation/v1.1.md`

## Summary

Each Lucian skin now has its own look and sounds for Q, W, E, R, basic attacks and the muzzle flash. The Skin Shop has a Preview pop-up that plays them. Classic keeps 1.0's effects. Nothing in gameplay changed: hitboxes, damage, cast times and cooldowns are the same.
- **Four themed skins:** High Noon (hellfire), PROJECT (hologram), Pulsefire (time rift) and Vampire (blood). Each has its own beam, missile, cross, dash trail, bullets, basic shot and muzzle flash (game design doc §10).
- **16 new sounds:** four per themed skin (Q, W, E and the shot, which is also R's).
- **Each skin carries an effect set** (`SkinFx`). The skills ask it for their pieces, so the skill code only changed in a few lines.
- **A Preview button** on every skin card opens a pop-up with Lucian and the training dummy. It plays Q, W, E, R and Attack, or all five in a loop (`main_screen.md`, Section 2).
- **Low effects** keeps only the main shapes, in the skin's colours.
- **Version 1.1.0** is set in `project.godot` and `export_presets.cfg`, and the README names the new zip.

The test suite grew from **1604 to 1653 tests**, and all of them pass. Each skin's Q, W (cross and missile in flight), E, R and basic attack was checked in screenshots from a real game window.

## Verification

- **Unit and scene tests (GUT):** **1653 of 1653 pass** (645.6 s), up from 1604 before V1.1 (638.7 s). The run shows no orphans and no leak lines at exit; only the 2 known GUT "unfreed children" warnings remain, as before V1.1.
  - They cover every skin's effect set, the sounds (every sound has a recipe, and each is as loud as the Classic one it replaces), the pieces' size and lifetime, Low effects, gameplay unchanged on all five skins, the wiring of every skill, and the preview.
- **Screenshot runs in a real window:** three scenarios, **43 PNGs**, saved in `docs/report/v1.1/`:
  - `skin_fx`: 36 shots, 6 for each of the 5 skins and 6 for Vampire on Low effects (Q, W's cross, W in flight, E, R and a basic attack).
  - `skin_preview`: 5 shots.
  - `main_skins`: 2 shots.
  - The console output was searched: **0 "triangulation" lines and 0 "ERROR" lines** in all three runs. (This closes the check left open in Task 6.)
  - After the final review's fixes, I re-took all three and looked at the new and changed images: every W and E shot of Pulsefire and Vampire, High Noon's Q, and every `_w_flight` and `_attack` shot. They match the spec. `skin_preview_2_e.png` still shows W's cross finishing, as explained above.
- **Found and fixed during the work:**
  1. The `skin_fx` scenario took W's shot before the missile landed. It now waits for the landing (`a9f92a4`).
  2. Skin sounds were scaled to a freshly generated Classic recipe, whose random noise gave a different peak from the Classic sound actually played. They now match the cached Classic stream's peak, and the loudness test is stable (`7e5c0d9`).
  3. A static Classic effect set in Lucian made the engine print leak lines at exit when the preview tests ran alone. The fallback now uses Classic's own set (`7e5c0d9`).
  4. A preview kept playing, with sound, when you switched to another main-screen section. The shop now closes its preview when hidden (`7e5c0d9`).

## Fixes from the final review

The whole-branch review asked for these. Code and screenshots are in the last code commit (`bebd82f`); the doc corrections are in the docs commit after it.

- **Pulsefire's W shockwave** ended at 220 px, circling the whole cross like a hit area. It now ends at 1.5 arm widths (90 px at rank 1), a burst at the centre. A test checks it never leaves that reach (`PulsefireBlast.wave_radius`).
- **Vampire's bats** are easier to see: rim 1.5 to 2.5 px, W's bats 28 to 36 px, the dash's 22 to 28 px. W's bat count is one constant (`BATS`).
- **High Noon's Q embers** drift less (`drag` 3.0), staying near the beam.
- **The preview's `close()`** does nothing if it is already closing, so `closed` fires once; the shop clears its `preview` only if it still points at the preview that closed. A test covers both.
- **`Lucian.fx()`** returns a plain `SkinFx` if neither the skin nor Classic has one, so no static state is needed.
- **Plain shot looks** (High Noon, PROJECT, Pulsefire) stop processing unless they are W's missile on high effects. A test covers it.
- **New screenshots:** `_w_flight` and `_attack` for every skin (12 PNGs), so W's missile and basic attacks are now seen too. The earlier claim that every effect was checked was only true after these.
- **Docs:** every PNG count is the real one (43; the earlier 35 was wrong); "no orphans" now also names the 2 known GUT warnings; the note on the preview's E shot; the commit range; the known limits.

## Known limits

- **The sounds are synthesized placeholders,** like 1.0's, and were never heard.
- **Some details reach a little past the hitbox edge:** High Noon's and PROJECT's Q sparks, and Pulsefire's beam rings and the clock at the muzzle, and Vampire W's blood drops, which fly into the diagonals between the arms. They are small and fade within 0.6 s. Pulsefire's W shockwave stays at the centre (it ends 1.5 arm widths out).
- **Vampire's bats are dark** and read mostly by their red rim on the dark floor. They are bigger now (36 px in W, 28 px in the dash) with a 2.5 px rim.
- **On Low effects, shots keep their static shape details:** Pulsefire's rings, PROJECT's trailing pixels and High Noon's smoke tail. Only their animation stops.
- **Tests:**
  - GUT's 2 warnings are the same as before V1.1: test scripts that leave a node or two unfreed (`test_act4`, `test_lucian_skills`).
  - `test_monsters`'s raptor-spread test waits on wall-clock time and can fail under load (known since Phase 10).
  - The full suite takes about 11 minutes.

## Manual playtest checklist (for you)

1. **Each skin in Training:** cast Q, W, E and R, and fire basic attacks. Check each has its own look and sound, and that nothing feels longer or wider than it hits.
2. **Settings, Low effects:** check that only the beam, missile, cross and bullets show, with no muzzle flash or dash trail.
3. **Skin Shop, Preview:** open it on an owned and an unowned skin. Check the loop starts by itself, each button plays one effect, and ✕ and ESC close it.
4. **Switch to the Evolution Tree** with a preview open: it closes, and the sound stops.
5. **Listen to the 16 new sounds.** They were never heard by a person.

## Feedback and suggestions

- **Sounds:** if any skin's sound is off, each is one recipe in `Sfx._generate`, so it is easy to retune.
- **Music** is still missing, and every sound is a generated placeholder.
