### 27: Endless boss rewards scale with the tier

### 33: Arrow keys and Enter in menus
- **New `src/ui/menu/menu_keys.gd`** (`class_name MenuKeys`, RefCounted). It holds the buttons of one page.
  - `handle(event) -> bool`:
    - Up and Down (Left and Right too, for a pop-up's side-by-side buttons) move a lit index. It skips hidden and disabled buttons and wraps around.
    - Enter or Keypad Enter presses the lit button (`pressed.emit()` plus its click).
    - It returns true when it used the key.
  - **Lit look:** the button's own hover stylebox and hover font color are copied into its normal ones. The originals are kept in meta and put back when it's no longer lit. This works for `MenuEntry` and for `UiStyle.style_button` buttons alike.
  - When the mouse enters a button, the lit index moves there, so the mouse and the keys agree.
  - Nothing is lit until the first arrow key, except in confirm pop-ups (below).
- **Wiring**, each into its existing `_input`:
  - `title_screen.gd` (98-107): the menu, slot and difficulty pages.
  - `screen_switcher.gd` (30-47): the pause menu (`game_menu.gd`).
  - `main_screen.gd` (80-93): the gear menu and its slot page.
  - **`confirm_popup.gd` (134-143):** the confirm button starts lit, so Enter confirms at once.
- No `focus_mode` changes, so Space keeps meaning Center camera.
- **Tests:** a new `test_menu_keys.gd`:
